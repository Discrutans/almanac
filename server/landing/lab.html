Almanac на этом ПК

Сервер уже запущен. Телефон подключается через WireGuard на MikroTik, без открытия порта 8080 в интернет.

1. Проверка API

В Almanac → Профили → Ссылки и API вставьте этот адрес:

http://localhost:8080

2. WireGuard на hAP ax S

ПК остаётся на кабеле 192.168.10.0/24 (bridge-lan). На MikroTik — WG-сервер. На телефоне — клиент. С улицы телефон заходит в туннель и ходит на IP ПК. Сначала один раз вставьте server/scripts/mikrotik/hap-ax-s-optimize.rsc в Terminal (кабель 192.168.10.x). Затем этот генератор: только wg-almanac, peer’ы и handshake перед «INPUT drop WAN». Wi‑Fi, CAKE и DHCP не трогает.

Скачать almanac-phone.conf
